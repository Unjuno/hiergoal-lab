## 5. 結果を読むときの区別

- **オフラインの成功：** 装置・採点・再生の検査。モデルの性能測定ではない。
- **試行のPASS：** その課題・予算での最終採点合格。比較優位とは別。
- **監査のPASS：** 記録された条件・遷移・結果の整合性。手法の有効性とは別。
- **有限基準のPASS/FAIL：** 事前指定した範囲の判定。任意課題への一般化ではない。
- **UNCERTAIN：** 証拠不足や対象外など、判定を確定できない状態。勝手に成功や失敗へ変換しない。
