# Hermes × OpenCode Free ACP：階層的サブゴール研究プロトコル

> **作成時点のプロトコル（履歴）。** 本文はOpenCode Free ACP経路を計画した時点の条件・未確認事項を保持する。無料モデルの提供状況や利用条件の現在値を保証する文書ではない。後に実施したHermes + Luna実験は別経路であり、OpenCode Free経路の実施証拠として扱わない。現在の結果と主張範囲は[2026年11月26日の結果整理](results_20261126_ja.md)を参照。下記手順は履歴資料であり、追加実験の開始予定ではない。

## 1. 目的と研究上の区別

Hermes Agent の外部オーケストレーターが、ユーザー固定の長期目標→AIが提案する中期マイルストーン→短期実行タスクを管理し、各タスクを独立テストで検証して、失敗時に局所的な再計画を行えるか観測する。

**事実：** GitHub Actions で合成（模擬）Hermes のエンドツーエンドテストが成功した。実際の OpenCode 無料モデルで実行したことはまだない。

**推論：** H-JEPAの階層的な目標生成・時間分解は、LLMエージェント実行の設計上の動機になる。ただしJEPAの学習機構や性能は今回再現していない。

**不確実：** OpenCode無料モデルの提供期間・利用制限・ツール性能・モデル出力品質は変わり得る。1事例の成否だけでは性能の改善効果は主張できない。

## 2. 実験環境・実装前提

| 項目 | 構成 |
|---|---|
| オーケストレーター | Python 3.11+、標準ライブラリ |
| エージェント | Hermes Agent 0.22.2以上 |
| 推論通信 | OpenCode v2 CLI の ACP、コミュニティ製 opencode-free-acp v0.4.0 |
| ACPプラグイン固定 | Git commit 0ef669a84c024661c03d34768c118275e93aa713 |
| モデル | opencode/glm-5.3-flash-free（無料提供は期限・条件付き） |
| Hermesプロファイル | hiergoal-free（他の設定をコピーしない） |
| APIキー | OpenAI APIキー不要。OpenCode側の正規ログインは必要な場合あり |
| 比較対象 | なし。単一ケース観察 |
| 課題 | Python CSV台帳の修正、独立受け入れ条件6件・可視テスト3件 |
| 重要制限 | terminal/fileツールにOS隔離なし。コンテナや権限分離を推奨 |

OpenCode公式の無料モデルAPIは第三者からの直接HTTPリクエストを403で拒否する。今回は実OpenCode CLIをACP経由で呼び出す。ただしOpenCode・モデル提供者の利用規約が全用途を許可すると推定しない。権限拒否・利用制限が出たら止める。

専用のHermesプロファイルには有料モデルへのフォールバックを含めない。実験実行時には設定検査を行い、有料モデル指定や不明なプロファイルを拒否する。旧Lunaスクリプトは別経路として明示的にオプトインしない限り課金実行しない。

## 3. H / T / D / C / U

**H（反証可能仮説）:** Hermesは、固定した長期目標の下で妥当な中期・短期目標を生成し、依存関係を守ってPython修正を実行し、独立テストの全9件を通過できる。短期目標が失敗した場合、受け入れ条件を変更せず再計画できる。

**T（最小検証）:** n_min=1課題×1実行。最大12回のHermes推論呼び出し、各呼び出し最大18ツール反復、最大2回の再計画、各呼び出し最大600秒。逐次停止は1ケース終了または停止条件到達時。実行前に無料モデルの存在とプロファイル設定をチェックする。

**D（合否）:**
- PASS：プロトコルに準拠した実行の後、独立テスト6件・可視テスト3件の全PASS、かつ元テスト不変。
- FAIL：計画JSONが不正、依存関係が循環、検証不合格、明確なCLI失敗、再計画上限。
- UNCERTAIN：タイムアウト、JSONL結果欠落、ネットワーク障害、推論の認証／権限不確定、バックエンド停止未確認など。

**C（対立仮説）:** 外部のサブゴール管理が実行動作に寄与しない／低性能モデルがJSON計画を生成できない／ローカル環境の権限やツール制限が原因で失敗する／独立テストの設計が目標と不一致。

**U（不確かさ）:** モデル非決定性、Hermes/OpenCode/ACPプラグインのバージョン、ネットワーク、モデルの無料期間・上限、トークン欠測、実行ホストの性能。単一ケースのため成功率の推定誤差や合成標準不確かさ u_c・包含係数 k は同定しない。

## 4. 収集指標と単位

| 計測項目 | 意味（日本語） | 単位（SI） | 定義・定義域 | 型 |
|---|---|---|---|---|
| elapsed_seconds | Hermes呼び出し時間 | s | 単調時計から測定、0以上 | 実数スカラー |
| calls | Hermes呼び出し件数 | 1（無次元） | 0以上の整数 | 整数スカラー |
| replans | 置換された短期目標件数 | 1（無次元） | 0以上の整数、最大2 | 整数スカラー |
| tool_calls | Hermesが発行したツール呼び出し件数 | 1（無次元） | 実行ログで観測された件数のみ | 整数スカラー |
| token_usage | 推論トークン件数 | 1（無次元） | ACPでは未計測の可能性あり、欠測はnull | 整数スカラーまたは欠測 |
| estimated_visible_usd | 推定請求額 | USD（SI外） | ACPのトークン請求値がない場合null。0とは扱わない | 実数スカラーまたは欠測 |
| tests_run | 外部テスト実行件数 | 1（無次元） | 独立6件／可視3件が必要 | 整数スカラー |

**単位チェック：** 秒は時間のみを表し、トークン件数や課金額と足し合わせない。件数は無次元。利用額は貨幣単位で、未計測データから算出しない。

## 5. 最小実行手順

1. GitHubからクローンし、オフライン単体テストと --dry-run を実行。
2. OpenCode v2 を正規に導入し、opencode models opencode で当該無料モデルを確認。
3. bash scripts/setup_opencode_free.sh を実行。モデル提供期間・利用規約を確認。
4. 隔離したPC／コンテナ内で python3 -m hiergoal.controller --ack-unsandboxed を実行。
5. runs/hiergoal-.../state.json、records.json、各stream JSONL、gate JSONの整合性を確認。
6. 生ログの機密情報をレビューし、条件・モデル・バージョン・失敗条件・制限を添えて公開する。
7. 再現可能な結果だけを Hermes Issue #156054 に関連付ける。
